# Siriva: презентация для жюри

Проект: [[map/Es]]. Питч на русском, 12 слайдов, примерно 4 минуты. Эта версия находится отдельно от первого питча `es/pitch/Siriva-pitch.*`.

## Готовые файлы

- [Редактируемый PowerPoint](output/Siriva-pitch-v2.pptx): текст, три таблицы, диаграмма с данными во встроенной книге Excel. Экраны продукта и декоративные объекты - изображения.
- [PDF для показа](output/Siriva-pitch-v2.pdf): 12 страниц 16:9, из проверенных рендеров 1920 x 1080. Текст в PDF является частью изображения. Для редактирования используйте PowerPoint.
- [[es/pitch/v2/SPEECH]]: общий спич с таймингом, без распределения ролей. Источники также находятся в заметках каждого слайда PowerPoint.

## Содержание

1. Siriva: ежедневные упражнения для речи и памяти.
2. Одинаковый результат может скрывать разные усилия.
3. Занятие в браузере и доступность.
4. Что измеряют три речевых упражнения.
5. Профиль пяти функций.
6. Обходной путь при сниженной речи.
7. Гибридная матрица TRIBE v2.
8. Корреляция по отдельным функциям.
9. Динамика для близкого.
10. Пять доступных упражнений прототипа.
11. Планируемый пилот на 20-30 участниках.
12. Команда и запрос клиническому партнёру.

## Источники и формулировки

Содержание соответствует сохранённым результатам [[es/tribe/REPORT-v2]], матрице `es/tribe/out/load_matrix.hybrid.json` и текущему коду. Для TRIBE указаны звук и текст на английском, без видеовхода. Корреляция 0,88 / 0,68 / 0,03 сравнивает модель с собственной предварительной оценкой по типу задания. Это не независимая экспертная разметка и не точность классификатора. Данные пациентов синтетические, клинической проверки пока нет. Размер пилота - план.

## Использованные навыки

Из репозитория: [[agents/pitch-deck]] (история, заметки докладчика, редактируемость), [[skills/humanizer/SKILL]] (текст без рекламных обещаний и искусственных противопоставлений). Сборка и проверка - установленный навык Presentations, через Artifact Tool и живую презентацию. Палитра и шрифт следуют [[es/docs/DESIGN-MEDTECH]], раздел 12. Иллюстрации и экраны взяты из существующих материалов Siriva.

## Исходники

- `src/build.mjs`: содержание и композиция слайдов. Используется в живой Artifact Session.
- `src/export.mjs`: экспорт PowerPoint и проверка OOXML, геометрии, шрифтов, встроенной книги данных графика и обратного импорта.
- `src/content.json`: текст, тайминг и источники каждого слайда.
- `preview/`: локальные PNG для визуальной проверки, в git не входят.

Повторная сборка использует поставляемую среду Codex (путь `CODEX_RUNTIME` в `src/export.mjs`). Финализатор требует новый путь для каждого готового PowerPoint и не перезаписывает существующий файл.
