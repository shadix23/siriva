# Готовые классификаторы речи при деменции: варианты для Es

Дата поиска: 14.11.2026. Метаданные получены через HF API и страницы моделей (пересказ страниц делала малая модель, поэтому перед использованием откройте карточку сами). Веса не скачивались. Проект некоммерческий, хакатонный прототип.

## Главный вывод

Надёжного готового классификатора деменции по речи с проверяемой точностью и явной лицензией найти не удалось. Всё, что лежит на HF, это студенческие или эксперименталь­ные чекпойнты без описания данных и без честного теста. Единственный с лицензией и текстовым входом (vjsyong, MIT) заявляет только accuracy на обучении. Опубликованные числа (0.83-0.85) относятся к коду обучения на ADReSSo, а не к скачиваемым весам.

## Юридический риск

- Ground Rules TalkBank ([rules](https://talkbank.org/0share/rules.html)): лицензия "precludes the incorporation of the data in commercial products", включая LLM. Коммерческим организациям разрешено получать доступ для разработки алгоритмов, но "the data themselves cannot be included in models". Перераспределение медиа без разрешения владельца корпуса запрещено. При публикации нужно цитировать корпус.
- Пробел: прямого пункта "можно ли публиковать веса модели, обученной на данных" я не нашёл. Для некоммерческого прототипа риск ниже, но он не нулевой. Для питча честнее сказать: "лицензия на данные не проверена юристом".
- Ни у одной из моделей в карточке не заявлено, что DementiaBank был источником и что условия соблюдены. Явная лицензия есть только у vjsyong (MIT) и shreyasgite (Apache-2.0), но она относится к весам, не к данным обучения. Происхождение vjsyong неизвестно, поэтому MIT не снимает вопрос о данных.
- Страница DementiaBank на момент поиска несёт баннер о пересмотре репозитория. Условия могут измениться.

## Открытый размеченный тест

Открытого размеченного набора речи при деменции с понятной лицензией я не подтвердил.
- DementiaBank/Pitt/ADReSS: закрыт для членов консорциума, использовать для проверки у нас нельзя.
- [PARLO Dementia Corpus](https://arxiv.org/abs/2603.03471) (немецкий, 208 участников: AD/MCI, деменция, норма): заявлен как публичный, но ссылки на скачивание и лицензия на странице не найдены. Язык не наш. Пробел по условиям.
- CLAC (английский, Cookie Theft): только условно здоровые, пациентов нет, пригоден лишь для проверки ложных срабатываний на норме.
- Китайский набор MCI (AACL 2020, 185 норма + 141 MCI): публичность не подтверждена.
Итог: честно проверить любую модель на казахской или русской речи у нас нечем. Допустимый минимум: свои записи здоровых добровольцев (ложные срабатывания), без утверждений о чувствительности.

## Рекомендация

Если пользователь настаивает на готовой модели, единственный формально пригодный вариант: vjsyong/xlm-roberta-dementia_detection (текст на входе после ASR, многоязычная база, MIT, запуск на CPU). Оговорки, которые нужно показывать в питче:
1. Данные обучения неизвестны, теста нет, заявлено только train accuracy 0.896 с признаками переобучения. Это не оценка качества.
2. Нет доказательства, что модель работает на казахском или русском.
3. Нельзя называть это диагностикой. Только "демонстрация пайплайна" или "индикатор для обсуждения с врачом".
4. Ссылаться на 0.83-0.85 (ADReSSo, роберта и whisper) можно только как на опубликованные результаты других авторов на английском, не как на нашу модель.

Более честная альтернатива для питча: не заявлять классификатор, а показывать признаки речи (паузы, лексическое разнообразие, скорость) как неклинические метрики динамики у самого человека, без порога "норма/деменция". Это не требует DementiaBank.
