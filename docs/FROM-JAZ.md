# Es: что взять из JAZ

Источник: `experience/JAZ.md` (подтверждённый проект). Аудитория Es другая: пожилые люди с ранними нарушениями и их близкие, врач как второй зритель. Жюри то же.

## 1. Главный экран-«меню задач» вместо дашборда (S1, S2)
- Где в JAZ: прод `/`, код `jaz/dist/metodist.js:229` (`homeUI`); полоса из 3 шагов и 6 карточек с живым статусом; переключатель A / A+ / A++.
- Адаптация: два главных экрана вместо одного. Пациент: одна крупная кнопка «Сегодняшние упражнения» и 2-3 карточки (описание картинки, называние, пересказ) со статусом «готово / ждёт». Близкий: карточки «Как прошла неделя», «Траектория», «Что обсудить со специалистом» с живым статусом. Размер текста A / A+ / A++ сделать по умолчанию крупным.
- Не переносить: плотные карточки с цифрами, термины со значком «?» (у пациента вообще без терминов), баллы и красные пороги на экране пациента (план: «без баллов и оценок»). Тепловую карту S5 использовать только на экране близкого и врача, и в мягких цветах.

## 2. Скелет демо и питча: слайд пути + сценарий из тех же шагов + ответы на вопросы (P1, P3, P4, V3)
- Где в JAZ: `jaz/docs/PITCH.md` (порядок аргументов с источниками и пометкой «оценка»); слайд «Қалай көрінеді» (4 кадра пути с подписями «где. что даёт»); живое демо `jaz/docs/PITCH-SPEECH.md` (раздел «Живое демо») и `jaz/docs/dev/HANDOFF.md` §6; таблица «Вопросы жюри» в конце PITCH-SPEECH; видео 0:05 реальный захват, 0:05-0:35 по шагам пути.
- Адаптация: шаги слайда и живого демо совпадают с «Сценарием демо» плана (описание картинки -> профиль -> два пациента -> экран близкого -> цифры). Каждый шаг уместить в 1 фразу «что видит жюри». Блок «Неудобные вопросы» оформить таблицей «вопрос / суть ответа» (формат P4) и добавить вопросы про данные и согласие на запись голоса. Если делаем видео: открыть болью близкого («заметил, когда уже очевидно»), на 0:05 показать реальный экран, сделать две версии, с голосом и без (V1, V2, V5). Видеозапись демо на случай отказа сети: порядок сцен тот же.
- Не переносить: геймификацию, маскота, яркие синие карточки, ирис-переходы и музыку 120 BPM. Тон спокойный, без «игры» и без обещаний лечения. Цифру «190 часов» заменить только на подтверждённые метрики (ADReSS), любую оценку помечать «болжам / оценка».

## 3. Честность с данными: метка синтетики и README «проверить за 2 минуты» (S3)
- Где в JAZ: метка «Демо-деректер (синтетика)» в шапке главной; `jaz/README.md` разделы «Проверить за 2 минуты» (6 шагов, без регистрации, данные уже загружены, язык переключается кнопкой) и таблица ссылок с QR; ответ «Данные учеников?» в PITCH-SPEECH (имена заменяются кодами).
- Адаптация: метка «Синтетический пациент, данные не реальные» на каждом экране с демо, включая профиль и экран близкого. README Es: ссылка на демо без регистрации, шаги по сценарию демо, отдельный абзац «чего продукт не делает» (не диагноз, не лечение), как хранится голос (признаки вместо сырого аудио), право удалить данные. Синтетическая история на 12 недель заранее загружена, как 147 учеников в JAZ.
- Не переносить: режимы по ролям Методист/Ученик с переключателем (в MVP аккаунтов и ролей нет, достаточно двух экранов по ссылке). Не заявлять точность на реальных людях: пометить, что валидации на пациентах нет.
