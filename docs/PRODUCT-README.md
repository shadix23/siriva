# Siriva - ежедневные упражнения для речи и памяти

**Siriva** - веб-платформа когнитивной реабилитации. Человек с ранними когнитивными трудностями выполняет короткие упражнения, и каждое из них одновременно измеряет его функции по голосу и поведению. Система строит **профиль из пяти функций** (эпизодическая память, доступ к слову, построение фраз, внимание, скорость обработки), подбирает следующие упражнения адресно и показывает близкому **динамику по неделям**. Если речевая функция снижена, подбор не продолжает давить на неё, а тренирует нужную функцию через сохранные каналы (зрительный, пространственный). Работает на русском и английском. Интерфейс на русском.

Это прототип для хакатона. Данные демо синтетические, на реальных пациентах продукт не проверялся.

## Проверить за 2 минуты

Регистрация не нужна, в демо уже загружены три синтетических пациента (подписано в интерфейсе: «Синтетический пациент, данные не реальные»). Запуск и адреса: раздел «Запуск» ниже.

1. Откройте **http://127.0.0.1:3000/demo**. Демо идёт по шагам, переход клавишей или кнопкой.
2. **Запись вживую.** Опишите вслух картинку (30-60 секунд, по-русски или по-английски). Паузы, время до первого слова и скорость речи появляются на экране сразу, затем приходит распознанный текст и признаки.
3. **Профиль.** Лепестковая диаграмма по пяти функциям и её сдвиг за 12 недель у синтетической пациентки «Сауле, 68 лет». Ниже микрометрики (пауза перед содержательным словом, слов в минуту в «Назовите животных», сколько сохранилось из рассказа через 20 минут).
4. **Обходной путь (главный кадр).** Два пациента с одинаково сниженной памятью и разной речью получают разные программы. У второго речевых заданий нет: память тренируется через зрительные и пространственные задания.
5. **Экран близкого.** Траектория по неделям и спокойное сообщение: динамика по доступу к слову идёт ниже ориентира, стоит обсудить со специалистом.
6. **Цифры.** Что подтверждено, а что ещё ждёт данных (честно, см. «Что заглушено»).
7. Вне демо: **http://127.0.0.1:3000** - занятие пациента (согласие, программа на сегодня, упражнения), **/family** - экран близкого, **/settings/delete** - удаление всех данных.

## Что работает сейчас

- Три упражнения с записью голоса: описание картинки (две оригинальные сцены), «Назовите животных за минуту», пересказ рассказа сразу и через 20 минут. Два неречевых упражнения (последовательность на поле, узнавание картинок).
- Распознавание речи **локально, без сети** (Whisper): текст с таймингами слов. Модель прогревается при старте, ответ на 60-90 секунд речи приходит примерно за 8-12 секунд.
- Речевые признаки: паузы, время до первого слова, скорость речи, разнообразие слов, местоимения, длина фраз, запинки; беглость называния по 15-секундным отрезкам с кластерами; потеря смысловых единиц пересказа за 20 минут. Фоновая телеметрия: время до первого действия, подсказки, прерывания.
- Профиль из пяти функций и траектория по неделям с флагом тренда для близкого. Прозрачные веса, у каждого балла видно, из чего он собран.
- Подбор программы: цель - просевшая функция, сниженные функции обходятся, суммарная нагрузка за занятие ограничена, уровень сложности подбирает **IRT** (модель Раша): по результатам пациента оценивается способность по каждой функции, выбирается уровень с предсказанной вероятностью успеха около 0,75 (пока данных мало, работает правило «точность 70-80%»). Трудность уровней откалибрована на синтетической популяции, не на реальных пациентах.
- **Модель забывания** для повторов: для рассказов, наборов картинок и последовательностей оценивается период полуразрушения следа, считается, когда предсказанное припоминание упадёт до 0,8, и программа показывает, что пора повторить и почему.
- **Исследовательская модель** (демонстрация конвейера): на английском описании картинки показывается оценка готовой текстовой модели (xlm-roberta, MIT). Это не наш результат: данные её обучения неизвестны, заявлена только точность на обучающих данных, проверочной оценки нет. Только на экранах демо, в профиль и подбор не входит.
- Согласие на запись голоса и отдельное разрешение показывать динамику близкому, удаление всех данных пациента одной кнопкой.

## Что заглушено (и как честно это показано в интерфейсе)

| Что | Состояние |
|---|---|
| Нагрузка упражнений на функции | Пока **предварительная** по типу задания (`placeholder, not TRIBE v2`). Прогон модели TRIBE v2 идёт отдельно, после его готовности матрица подключается одной переменной `ES_LOAD_MATRIX`. Тогда в интерфейсе и API источник сменится автоматически. Это предсказанная нагрузка модели, не измерение мозга пациента. |
| Классификатор на ADReSS | **Нашей модели нет**: ждём доступа к данным DementiaBank (подключена только готовая исследовательская модель как демонстрация, см. выше, точность не подтверждена). Будет только для английской речи. Для русской остаются временные метрики и профиль. Опубликованный ориентир (тест 48 человек, точность 0,75) показан как ориентир, не как наш результат. |
| Баллы профиля | Эвристика с документированными весами, **до калибровки**. Это положение относительно ориентиров, не норма. |
| IRT и модель забывания | Работают, но трудность уровней откалибрована на **синтетической** популяции, а параметры забывания не подгонялись на реальных данных. Пересчёт после появления реальных результатов. |
| Проверка на людях | Не проводилась. Все истории в демо синтетические. |

## Чего продукт не делает

- **Не даёт медицинских заключений** и не определяет состояние человека. Профиль функций и динамика это наблюдение, а не вывод. Флаг для близкого описывает тренд и всегда советует обсудить со специалистом.
- **Не хранит голос.** Аудио удаляется сразу после распознавания, сохраняются только числовые признаки. Текст расшифровки по умолчанию тоже не хранится.
- **Не отправляет голос наружу.** Распознавание локальное. Внешний сервис включается только явным `ES_TRANSCRIBER=groq` с ключом из окружения.
- **Не заменяет специалиста** и не обещает остановить процессы старения. Это ежедневная поддержка и наблюдение за динамикой.
- Не имеет аккаунтов и ролей: доступ к данным по ссылке и идентификатору (граница MVP).

## Архитектура

1. Браузер (Next.js): запись голоса (MediaRecorder), телеметрия событий, экраны пациента, профиля, близкого, демо.
2. API (FastAPI + SQLite): `/audio` принимает запись, возвращает текст с таймингами и признаки; хранит признаки, не аудио.
3. Речь: faster-whisper (модель `small`, int8, пакетная обработка окон) и признаки из таймингов слов.
4. Профиль и подбор: пять функций, траектория и флаг тренда, подбор по матрице «упражнение на функцию» с контролем дозы, IRT для сложности, модель забывания для повторов.
5. Матрица нагрузки: сейчас предварительная, затем предсказание TRIBE v2, считается офлайн один раз.

Контракт API: [docs/API-CONTRACT.md](docs/API-CONTRACT.md). Экраны и тексты: [docs/UX-SPEC.md](docs/UX-SPEC.md). Картинки: [docs/PICTURES.md](docs/PICTURES.md). Подробности бэкенда: [backend/README.md](backend/README.md).

## Запуск

Нужны macOS или Linux, Python 3.10+, Node 20+.

```bash
# один раз
cd es/backend && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cd ../web && npm install
# модель распознавания скачивается один раз при первом старте (около 150 МБ), потом работает офлайн

# каждый раз
es/start-demo.sh
```
`start-demo.sh` поднимает API и web (собирает web при необходимости), ждёт, пока модель распознавания прогреется (`transcriber_ready`), сбрасывает демо-данные и печатает адреса (по умолчанию приложение `http://127.0.0.1:3000`, API `http://127.0.0.1:8000`). Ctrl+C останавливает оба процесса. Сброс демо перед показом отдельно: `es/reset-demo.sh`.

Настройки через переменные окружения: `ES_WHISPER_MODEL` (`small` по умолчанию, `base` быстрее, но слабее по-русски), `ES_LOAD_MATRIX` (путь к матрице TRIBE v2), `ES_API_PORT`, `ES_WEB_PORT`. Проверка бэкенда: `cd es/backend && .venv/bin/python -m pytest` (офлайн).
