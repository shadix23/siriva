# Siriva backend

Python-ядро (речевые признаки, беглость, пересказ, профиль, подбор программы, синтетика) и FastAPI + SQLite. Контракт для фронтенда: `../docs/API-CONTRACT.md`.

## Установка

```bash
cd es/backend
/Library/Frameworks/Python.framework/Versions/3.10/bin/python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```
ffmpeg не нужен: faster-whisper читает webm/opus через PyAV. Модель Whisper (по умолчанию `base`) скачивается один раз в `models/` при первом реальном распознавании, дальше всё работает офлайн.

## Запуск

```bash
.venv/bin/python -m es_api            # http://127.0.0.1:8000 , документация /docs
# или: .venv/bin/uvicorn es_api.main:app_factory --factory --port 8000
```
Демо-пациенты создаются при старте. База: `data/es.sqlite3` (путь: `ES_DB_PATH`).

Переменные окружения (все необязательны): `ES_WHISPER_MODEL` (base), `ES_TRANSCRIBER` (`local` по умолчанию; `groq`, либо `auto`: Groq, если задан `GROQ_API_KEY`), `GROQ_API_KEY` (только из окружения, в код и git не попадает), `ES_STORE_TRANSCRIPTS=1`, `ES_KEEP_AUDIO=1`, `ES_LOAD_MATRIX` (путь к настоящей матрице), `ES_CORS_ORIGINS`, `ES_DELAY_MINUTES` (20, сократить для показа отложенного пересказа), `ES_TRANSCRIBE_TIMEOUT` (60 секунд).
Пороги профиля, флага тренда и подбора лежат в одном файле `es_core/config.py` (пересмотреть после калибровки).
Голос уходит наружу только при `ES_TRANSCRIBER=groq` или `auto` с ключом.

## Тесты

```bash
.venv/bin/python -m pytest          # офлайн, модели не качает, около 15 с (импорт faster-whisper)
```
Покрытие: признаки, беглость, пересказ, профиль, подбор и доза, обходной путь, флаг тренда, адаптер Groq (мок), чтение webm/opus, API (успех, неверные данные, согласие, удаление), проверка запрещённых слов.

Скорость распознавания: `PYTHONPATH=. .venv/bin/python scripts/bench_transcribe.py base small`.
Ручная сквозная проверка (нужна модель, при первом запуске скачивается около 145 МБ): `PYTHONPATH=. .venv/bin/python scripts/e2e_say.py en` (или `ru`): речь из `say`, перекодирование в webm/opus, `/audio`, признаки.
Перегенерация фикстур: `PYTHONPATH=. .venv/bin/python scripts/make_fixtures.py`. Матрица и библиотека: `PYTHONPATH=. .venv/bin/python scripts/build_placeholder_matrix.py`. Документ по картинкам: `PYTHONPATH=. .venv/bin/python scripts/build_pictures_doc.py`.

## Распознавание: модель, замеры, прогрев

Модель по умолчанию `small` (int8, CPU, пакетная обработка окон, `beam_size=1`); `ES_WHISPER_MODEL=base` быстрее, но слабее по-русски. Замеры `scripts/bench_transcribe.py` на Apple M5 (16 ГБ), речь из `say` в webm/opus, время ответа распознавания в секундах. Машина в момент замеров была загружена другими процессами (load average около 12), на спокойной машине быстрее.

| Модель | ru 60 с | ru 90 с | en 60 с | en 90 с | примечание |
|---|---|---|---|---|---|
| base, пакетно (по умолчанию) | 6,2 | 5,4 | 2,6 | 3,4 | русский местами слышит неточно («ураковины») |
| small, пакетно | 9,4 | 12,4 | 8,3 | 11,6 | русский лучше, но на 90 с выше цели 8 с |
| base, по окнам подряд (до оптимизации) | 20-33 | 33 | 17 | 27 | декодер упирается в накладные расходы шага |
| small, по окнам подряд | 110 | 177 | - | - | непригодно для сцены |

Свежий замер `small` на почти свободной машине (load average около 5): ru 60 с 8,5 с, ru 90 с 11,5 с, en 60 с 7,6 с, en 90 с 10,3 с. Для сцены выбран `small` ради русского (`base` в таблице выше быстрее, но слышит хуже). Временные признаки (паузы, задержки, скорость) от точности слов не зависят, а совпадение со смысловыми единицами щедрое. Если нужен точнее русский и машина свободна: `ES_WHISPER_MODEL=small` (проверьте время командой выше).
Прогрев: при старте сервера модель загружается и декодирует две коротких записи (ru, en) в фоне. `GET /health`: `transcriber_ready` становится `true` только после прогрева, `transcriber_state` показывает `cold`, `warming`, `ready` или `error`. Отключить: `ES_WARMUP=0`. Параметры: `ES_WHISPER_THREADS` (4), `ES_WHISPER_BATCH` (8, `0` отключает пакетный режим), `ES_WHISPER_BEAM` (1).
Файлы прогрева `es_core/data/warmup_*.pcm` создаёт `scripts/make_warmup_audio.py`.

## Исследовательский классификатор (демонстрация)

`es_core/research_classifier.py`: готовая текстовая модель `vjsyong/xlm-roberta-dementia_detection` (Hugging Face, MIT) на английском транскрипте описания картинки. Опционально: `pip install -r requirements-research.txt`, скачать веса в `models/research-classifier/` (в git не попадают) и один раз сконвертировать из TensorFlow: `PYTHONPATH=. .venv/bin/python scripts/convert_research_classifier.py` (команда загрузки в docstring скрипта). Без весов блок просто выключен. `ES_RESEARCH_CLASSIFIER=0` отключает. Прогрев при старте (около 20 с), оценка около 0,2 с. Оговорки модели, поля ответа и то, что результат не попадает в профиль и подбор: в `../docs/API-CONTRACT.md` (v0.4). Тесты на мок-модели без скачивания, один тест на настоящих весах пропускается, если их нет.

## IRT и повторы

- **IRT (Раш, 1PL).** `es_core/irt.py`. Трудности пяти уровней по каждому домену откалиброваны на 400 синтетических пациентах (EM по узлам Гаусса, `scripts/calibrate_irt.py`, результат `es_core/data/irt_calibration.json`, ошибка восстановления генерирующих значений 0,02-0,12). Способность пациента по домену: EAP с нормальным априорным распределением по накопленным результатам (таблица `ability_results`, пополняется из `/result`). Уровень: тот, где предсказанная вероятность успеха ближе всего к 0,75. Меньше 3 результатов в домене: правило 70-80% (`source: rule`). Демо-пациентам заранее засеяна история результатов.
- **Забывание.** `es_core/forgetting.py`: облегчённая half-life regression, `p = 2^(-t/h)`. Первая встреча с материалом задаёт `h` по силе запоминания, каждая проверка двигает `log h` на `1,2 * (q - p)` плюс бонус за успешное припоминание после паузы. Повтор назначается, когда `p` падает до 0,8. Таблица `memory_items`, рассказы обновляются сами после пересказа, остальные материалы через `/result` с `material_id`. Параметры не подгонялись на реальных данных.
- Все пороги в `es_core/config.py`.

## Подключение матрицы TRIBE v2

Одна переменная: `ES_LOAD_MATRIX=<путь к load_matrix.tribe_v2.json>` (формат как у заглушки: `source`, `label_ru`, `model_version`, `atlas`, `domains`, `domain_notes`, `loads`). `start-demo.sh` передаёт её дальше. Источник меняется везде: `/health` (`load_source`, `load_is_placeholder`, `load_label`), `/exercises`, `/program/today`, `/demo/bypass-scenario` (текст объяснения), `/demo/numbers` (`agreement` считается как Спирмен против заглушки, статус `ready`).
Перед показом проверьте файл: `PYTHONPATH=. .venv/bin/python scripts/check_matrix.py <путь>` (формат, покрытие 25 упражнений, согласованность, чистота обходного сценария). Тесты не зависят от матрицы: `ES_LOAD_MATRIX=<путь> .venv/bin/python -m pytest` проходит и с настоящей. Подставной файл для проверки лежит только во временных папках.

## Структура

- `es_core/`: `config.py` (все пороги), `pictures.py` (2 сцены для описания картинки, см. `../docs/PICTURES.md`), `agreement.py` (Спирмен для `/demo/numbers`), `texts.py`, `transcribe.py` (адаптеры), `features.py`, `fluency.py`, `retell.py` + `stories.py` (2 рассказа по 24 единицы), `profile.py` (веса и ориентиры в коде), `matrix.py` (загрузчик), `planner.py` (подбор, доза, сложность), `trend.py`, `synthetic.py`, `data/` (библиотека 25 упражнений, матрица).
- `es_api/`: `main.py` (эндпоинты), `db.py` (схема SQLite).

## Что заглушка и почему

- **Матрица нагрузки** `es_core/data/load_matrix.placeholder.json`: `source: "placeholder, not TRIBE v2"`, значения из априорных свойств типа задания. TRIBE v2 не прогонялся. Загрузчик `JsonMatrixLoader` принимает настоящий агрегат «стимул x домен» с `source`, `model_version`, `atlas`. Скорость обработки в матрице это только прокси темпа стимула, в профиле она берётся из телеметрии и речи. Эпизодическая память в профиле опирается на поведенческие метрики пересказа, а не на матрицу.
- **Профиль доменов**: прозрачная взвешенная эвристика (`profile.py`), ориентиры и веса до калибровки на ADReSS.
- **Классификатор ADReSS**: нет данных, не реализован (TODO в `profile.py`). В будущем только для английской речи.
- **Синтаксис и существительные**: простые прокси (длина высказывания, подчинительные слова, суффиксы), без POS-теггера.
- IRT и модель забывания работают, но откалиброваны на синтетических данных (TODO: реальные результаты, сравнение с FSRS).
- Аккаунтов и ролей нет: доступ по `id`.
