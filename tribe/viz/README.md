# Карты коры по выходу TRIBE v2

Это предсказание модели для усреднённого мозга по звуку и тексту стимула, не измерение конкретного человека.

## Как получено
- Вход: `es/tribe/features-v2/audio/*.npy` и `features-v2/text/*.npy` (английские стимулы v2; 1 Гц, 20484 вершины fsaverage5, float16). Каталог `features/` содержит прогон v1 (русский), он не используется.
- На упражнение: среднее по времени после отбрасывания первых 5 с. Затем z по стимулам для каждой вершины отдельно в каждой модальности (звук: 25 стимулов, текст: 9 речевых), модальности упражнения усредняются (как в `mac/v2/aggregate.py`). Цвет обрезан на +-2.
- Группы: речевые (9, `speech_output`) против зрительных/пространственных/моторных (11, по каналу). Разница = среднее z речевых минус среднее z зрительных.
- Контур: объединённая языковая маска `word_access` + `phrase_building` (`mac/work/masks_v2.npz`), только левое полушарие (в правом маски нет).
- Палитра: терракота (`--rec`) через бумагу к зелёному (`--accent`) из дизайн-токенов Siriva.

## Файлы
- `speech_story_retell_{ru,en}.png`, `visual_spatial_sequence_{ru,en}.png`, `diff_speech_minus_visual_{ru,en}.png` (1600x1480, белый фон, 200 dpi).
- Данные для 3D: `es/web/public/brain/mesh.json` и `loads.json` (значение 0..255 = (z+2)/4*255, 128 = 0, общая шкала).
- Пересборка: `cd es/tribe && .venv-mac/bin/python viz/make_viz.py`

## Оговорки
- Предсказание модели, не измерение; усреднённый мозг, не человек.
- Речевые и зрительные стимулы различаются прежде всего тем, что в одних есть речь в звуке, а в других нет. Разница отчасти отражает это, а не "когнитивную нагрузку".
- Зрительного входа в звуке и тексте нет, поэтому зрительная кора выше у зрительных заданий не будет (видео в эту выгрузку не входит).
- Карты по отдельному упражнению шумные (z по 25 стимулам); устойчива в основном групповая разница.
