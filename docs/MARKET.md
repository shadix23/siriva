# Siriva: рынок и бизнес-модель (факты для слайда)

Дата сбора: 15.11.2026. Метод: веб-поиск (standard), первоисточники там, где удалось открыть. Пункт про лицензию TRIBE v2 исключён по поправке пользователя.
Обозначения: **факт** = цифра есть в источнике; **расчёт** = арифметика из фактов; **гипотеза** = наше допущение, не факт; **нет данных** = не нашли.
Цены аналогов из [COMPETITORS.md](COMPETITORS.md) не дублируются, только пересчитаны в тенге.

Курс для пересчёта: официальный курс НБРК на 11.11.2026: 1 USD = 447,52 тг, 1 EUR = 502,21 тг, 1 RUB = 5,41 тг ([bank.kz, 11.11.2026](https://bank.kz/news/finansy-news/kursy-valyut-v-kazakhstane-na-11-noyabrya/); на nationalbank.kz не перепроверено).

## Короткие выводы для слайда

1. В Казахстане около **1,9 млн человек 65+ (9,2%)** на 01.01.2025 и около **2,8 млн 60+ (13,9%)**. К 2050 доля 60+ вырастет примерно до **19%** (ЕНПФ и ООН).
2. В мире **57 млн** людей с деменцией (ВОЗ, данные 2021), к 2050 прогноз **153 млн** (GBD, Lancet Public Health 2022). MCI: **15,6%** у людей 50+ (метаанализ, 2022), **6,7-25,2%** по возрастам 60-84 (AAN, 2018).
3. В Казахстане официально учтено только **11 087 случаев деменции (2025)**, местные оценки реального числа **115-150 тыс.**, оценки экспертов до 200 тыс. Разрыв между учётом и оценкой означает, что ранние стадии почти не выявляют. Оценки GBD именно по Казахстану не нашли.
4. Глобальный рынок: оценки агентств сильно расходятся из-за разных определений. «Цифровая когнитивная реабилитация» около **$6 млрд к 2034 (CAGR 10,5%)**, «ПО для тренировки мозга» **$10,2 млрд (2024) -> $32,2 млрд (2030), CAGR 21%**. Это оценки аналитических агентств, не аудированные данные.
5. Цены аналогов в тенге: массовые тренажёры **~4 500-6 300 тг/мес**, Constant Therapy **~13 400 тг/мес**, NeuroNation MED по возмещению в Германии **~80 000 тг/мес** (479,70 евро за 90 дней).
6. Кто платит в Казахстане: правила дистанционных медуслуг (приказ ҚР ДСМ-12, 2021) прямо включают **медицинскую реабилитацию** и оплату в рамках ГОБМП/ОСМС «в порядке, определяемом уполномоченным органом». Прецедентов оплаты приложения через ОСМС **не нашли**. Реалистичный путь: B2C (близкие) и B2B через лицензированные клиники.
7. Регуляторика: в ЕАЭС медизделием считается и «специальное программное обеспечение», если производитель предназначил его, среди прочего, для **медицинской реабилитации**. Позиционирование «когнитивная реабилитация при MCI» повышает риск, что продукт признают медизделием. Для пилота честнее «когнитивная тренировка, не диагностика и не лечение», для ОСМС и клиник понадобится регистрация.

## 7. TAM / SAM / SOM для Казахстана (гипотеза)

**Это расчёт на допущениях, не факт рынка.**

Формулы:
- Целевая группа N = (население 60+ x доля MCI) + (люди с деменцией x доля лёгкой стадии).
- TAM (деньги) = N x годовая цена.
- SAM = TAM x доля доступных онлайн (город, смартфон у пожилого или близкого, близкий готов участвовать).
- SOM = SAM x достижимая доля за 3 года.

Входные цифры:
- 60+ = 2,8 млн (факт, начало 2025).
- Доля MCI среди 60+ = 10-15% (допущение по Bai 2022 и Petersen 2018, локальных данных нет).
- Деменция = 150 тыс. (местная оценка 2021), доля лёгкой стадии 1/3 (допущение, источника нет).
- Годовая цена = 4 990 тг/мес x 12 = 59 880 тг (гипотеза цены, см. ниже).

| Уровень | Люди | Деньги в год | В USD |
|---|---|---|---|
| N без деменции: 2,8 млн x 10-15% | 280-420 тыс. | | |
| + лёгкая деменция: 150 тыс. x 1/3 | +50 тыс. | | |
| **TAM** | **330-470 тыс.** | **19,8-28,1 млрд тг** | **$44-63 млн** |
| **SAM** (50% доступны онлайн, допущение) | **165-235 тыс.** | **9,9-14,1 млрд тг** | **$22-31 млн** |
| **SOM** (1-2% SAM за 3 года, допущение) | **1 650-4 700 платящих** | **99-281 млн тг** | **$0,22-0,63 млн** |

Плюс B2B (гипотеза): 10 клиник x 100 пациентов в год x 15 000 тг за курс = 15 млн тг в год. Мало в деньгах, но важно как доказательство клинического использования.

Проверка на здравый смысл: SOM 1 650-4 700 человек это 0,06-0,17% от 2,8 млн людей 60+. Для сравнения, официальный учёт деменции 11 087 человек (2025).

## Допущения

1. Доля MCI среди 60+ в Казахстане 10-15%: перенос мировых данных (Bai 2022, Petersen 2018). Локальной эпидемиологии нет.
2. Реальное число людей с деменцией 150 тыс. (оценка 2021); доля лёгкой стадии 1/3 без источника.
3. 50% целевой группы доступны онлайн: доля интернет-пользователей 16-74 лет 96,2%, но разбивки по 60+ нет; городское население и готовность близких не проверены.
4. Достижимая доля 1-2% SAM за 3 года: ориентир для раннего стартапа, не рыночные данные.
5. Цены 2 990 / 4 990 / 15 000 тг: наша гипотеза, без опросов готовности платить.
6. Курс валют на 11.11.2026; цены аналогов могут меняться.
7. Платит семья (взрослые дети), а не сам пожилой: гипотеза, опросов нет.
